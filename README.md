## 📁 Troubleshooting tips

If the app fails to start, make sure you have the latest drivers for your graphics card. Some interface elements need modern hardware acceleration. If the generation step stalls, check your firewall settings to ensure Carrier has permission to communicate with your internal database. 

You can find log files in the folder where you installed the program. These files contain details about any errors discovered during the generation phase. Send these files to the support team if you encounter a persistent issue. They provide clear steps to fix common configuration conflicts. 

Maintain backups of your project folder regularly. Copy your project folder to a cloud drive or an external disk to ensure you never lose your progress during a system update or computer swap.
